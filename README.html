Версия перевода: 1.0.5
Версия игры: 0.20.0 (Steam build 25961942)

Нужна установленная Rain98 Demo из Steam. Перед установкой закройте игру и распакуйте весь архив.

Windows

  1. Откройте Русификатор_Rain98_Demo.exe.
  2. Проверьте папку игры. Если она не найдена, укажите папку с Rain98 Demo.exe.
  3. Выберите, сохранять ли резервную копию, и нажмите «Установить перевод».
  4. Дождитесь сообщения об успешной установке. Запускайте игру через Steam.

Steam Deck

  1. Перейдите в режим рабочего стола.
  2. Распакуйте архив целиком, например в «Загрузки». Откройте папку Steam_Deck; папка Данные должна остаться рядом с файлами запуска.
  3. Запустите com.github.hexelune.Rain98.InstallBackup.desktop или com.github.hexelune.Rain98.InstallNoBackup.desktop. Каждый файл сразу запускает свой режим, без меню выбора и консольного ввода. Если Dolphin спрашивает, выберите выполнение файла.
  4. Игра ищется в библиотеках Steam автоматически, включая карту памяти. Если папка не найдена однозначно, выберите папку с Rain98 Demo.exe и Rain98 Demo_Data в открывшемся окне. Дождитесь окна с результатом.
  5. Вернитесь в игровой режим и запускайте игру через Proton.

Нужны Python 3.10 или новее и KDialog либо Zenity для окон; в режиме рабочего стола SteamOS используется KDialog. Дополнительные модули Python и запуск Windows EXE через Proton для установки не нужны.

Обновление и язык

  • С предыдущей версии: распакуйте новый архив в отдельную папку. Сначала восстановите оригиналы установщиком предыдущей версии, затем установите новую. Для Steam Deck это файл удаления из прежнего пакета, затем один из двух файлов установки нового. Если старого пакета или копий нет, восстановите ресурсы через проверку целостности в Steam.
  • Перевод занимает английский языковой набор. Если выбран другой язык, переключитесь на English; после установки этот пункт называется «Русский».

Резервная копия и удаление

  • Резервное копирование можно отключить. Копируются только заменяемые ресурсы, без копии всей игры.
  • Уже сохранённые оригиналы не удаляются и не заменяются переведёнными файлами при повторной установке.
  • В Windows используйте проверку или «Восстановить оригинал» в установщике. На Steam Deck — com.github.hexelune.Rain98.Check.desktop или com.github.hexelune.Rain98.Uninstall.desktop. Проверка не заменяет ресурсы; удаление возвращает оригиналы из копии.
  • Оригиналы находятся в Rain98_RU_Backup внутри папки игры. Не удаляйте эту папку до восстановления.
  • Если резервной копии нет, проверьте целостность файлов игры в Steam, затем выберите «Восстановить оригинал» для очистки служебных данных установки. Сохранения установщик не меняет.
  • Поддерживается указанная сборка игры. После обновления Steam совместимость нужно проверить заново.

Если возникла проблема

  • Файл открывается как текст: в Dolphin откройте свойства файла .desktop, раздел разрешений, и разрешите выполнение. Затем выберите запуск. Не переносите отдельно один файл из архива.
  • Invalid unit name or type: удалите старую распаковку пакета или распакуйте этот архив в новую папку. Запускайте файл с коротким ASCII-именем из таблицы выше. Настройки KDE менять не требуется.
  • Окно не открылось: используйте режим рабочего стола и распакованный пакет. Проверьте наличие Python 3 и KDialog/Zenity. При повреждённом архиве скачайте его заново и распакуйте полностью; ошибка отсутствующего модуля не требует копирования файлов из других версий.
  • Установлена другая версия пакета: восстановите оригинал установщиком этой версии и установите новую. Смешивать папки разных выпусков нельзя.
  • Версия или контрольная сумма ресурсов отличается: пакет рассчитан на указанный Steam build. Уберите другие модификации, восстановите файлы через Steam и проверьте сборку игры. Не удаляйте резервную копию для обхода проверки.
  • Нет места: заменяется четыре ресурса; один исходный архив игры занимает около 3,7 ГиБ. Это копия заменяемого ресурса, а не всей игры. Кроме копии, нужно место для сборки нового ресурса и временного отката. Освободите место на диске игры или выберите установку без новых копий.
  • Нет доступа: убедитесь, что папки игры и распакованного пакета доступны для записи. На Deck не запускайте установщик через sudo; выбирайте папку своей библиотеки Steam.
  • «Закройте игру»: завершите сам процесс игры, в том числе зависшее окно. Сбой проверки процессов выводится отдельной ошибкой с системным кодом и не означает, что игра запущена.
  • Нужны подробности ошибки: на Deck журнал installer-last-run.log появляется в папке Steam_Deck/Данные; если она недоступна для записи — в ~/.local/state/Rain98_RU. Сохраните сообщение и журнал до следующего запуска.
  • Текст остался на другом языке: выберите английский языковой набор, который после установки отображается как «Русский», и перезапустите игру. После проверки целостности Steam перевод нужно установить заново.
