# Rain98 Demo — русский перевод

**Версия перевода:** 1.0.6

**Версия игры:** 0.20.1 (проверено на Steam build 26725370)

[Скачать для Windows и Steam Deck](https://github.com/hexelune/rain98-demo-ru/releases/download/v1.0.6/Rain98_Demo_RU_Windows_Steam_Deck_v1.0.6.zip) · [Инструкция](README.html)

- Переведена обновлённая сцена с Рейной во второй главе. Добавлена 151 строка и вычитано 25 изменённых строк.
- Шрифты, настройки текста и графические правки перенесены на ресурсы демоверсии 0.20.1.
- Совместимость на Windows и Steam Deck определяется содержимым игровых ресурсов. Номер Steam build указан для справки. Для несовместимых ресурсов нужна новая адаптация.
- Для каждого набора оригинальных ресурсов используется отдельная папка резервных копий.
- Исправлен сбой при выводе результата команды установки в Windows с CP1251.

На Windows запустите Русификатор_Rain98_Demo.exe из распакованного архива. На Steam Deck откройте нужный ярлык в папке Steam_Deck в режиме рабочего стола. Подробная инструкция с вариантами установки и восстановления входит в архив.
