# Rain98 Demo — русский перевод

**Версия перевода:** 1.0.5

**Версия игры:** 0.20.0 (Steam build 25961942)

**Исправление установщика Steam Deck:** 1

[Скачать исправленный пакет](https://github.com/hexelune/rain98-demo-ru/releases/download/v1.0.5-deckfix.1/Rain98_Demo_RU_Windows_Steam_Deck_v1.0.5_DeckFix1.zip) · [Подробная инструкция](README.html)

- Исправлен запуск из Dolphin/KDE при ошибке `Invalid unit name or type`: короткие технические ASCII-имена `.desktop`, русские подписи действий сохранены.
- Четыре прямых действия: установить с резервной копией, без неё, проверить перевод и удалить. Действие запускается одним нажатием, без отдельного меню и консольных вопросов.
- Уточнены HTML-инструкция, обновление и решение ошибки KDE. Настройки системы менять не требуется.
- Windows EXE, текст и игровые ресурсы сохранены из указанной версии перевода.

Распакуйте весь архив в **новую папку**. В `Steam_Deck` выберите нужное действие. Имена файлов начинаются с `com.github.hexelune.`; русские названия видны в подписи ярлыка. Старые ярлыки с длинными русскими именами не копируйте в новую папку. Для уже установленного перевода этой же версии повторная установка не требуется.

Windows: запустите EXE из архива.
