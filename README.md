# Rain98 Demo — русский перевод

**Версия перевода:** 1.0.5

**Версия игры:** 0.20.0 (Steam build 25961942)

[Скачать v1.0.5](https://github.com/hexelune/rain98-demo-ru/releases/download/v1.0.5/Rain98_Demo_RU_Windows_Steam_Deck_v1.0.5.zip) · [Подробная инструкция](README.html)

- 107 адресных редакторских правок после повторного чтения всех 4440 записей: русский порядок слов, смысловой акцент, сочетаемость и живые реакции.
- «Гладь воды» → «Водная гладь»; перестроены тяжёлые фразы повествования и диалогов с учётом доступных языков.
- Убрана мешающая обводка десяти материалов текста. Сохранены шрифты, метрики и исправление атласа для выбора «Себя».
- Полупрозрачные рамки диалогов сохранены как часть исходного оформления игры.
- Steam Deck: четыре понятных файла запуска — установка с резервной копией, установка без неё, проверка и удаление. Одно нажатие запускает действие; дополнительного меню и консольных вопросов нет.
- Резервируются только заменяемые ресурсы; существующие оригиналы сохраняются.
- Подробный HTML README: установка, обновление, восстановление и решение проблем. Оформление Windows-установщика сохранено.

Steam Deck: распакуйте весь архив в режиме рабочего стола. В папке `Steam_Deck` откройте нужный из четырёх файлов `.desktop`; папку данных оставьте рядом.

Windows: запустите EXE из архива, проверьте папку игры и установите перевод. После установки выберите «Русский».
