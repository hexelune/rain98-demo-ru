# Rain98 Demo — русский перевод

Неофициальный русификатор демоверсии для **Windows** и **Steam Deck (Proton)**. Перевод создан с нуля.

**[Скачать архив](https://github.com/hexelune/rain98-demo-ru/releases/latest/download/Rain98_Demo_RU_Windows_Steam_Deck_v1.0.0.zip)** · [Все выпуски](https://github.com/hexelune/rain98-demo-ru/releases)

Нужна [Rain98 Demo из Steam](https://store.steampowered.com/app/3738760/Rain98_Demo/), **Ver. 0.20.0 / Steam build 25961942**. Перед установкой закройте игру и оставьте около **5 ГБ свободного места** на диске игры.

## Установка

**Windows:** распакуйте весь архив, запустите `Русификатор_Rain98_Demo.exe`, проверьте найденную папку игры и нажмите **«Установить перевод»**. Затем запускайте игру через Steam.

**Steam Deck:** в режиме рабочего стола распакуйте весь архив и откройте `Steam_Deck/1. Установить перевод.desktop`. При запросе KDE разрешите запуск ярлыка. Дождитесь завершения в терминале и вернитесь в игровой режим. Требуется Python 3.10 или новее; дополнительные модули не нужны.

Перевод заменяет английский языковой набор. Если выбран другой язык, переключитесь на **English**; после установки этот пункт отображается как **«Русский»**.

Подробная инструкция находится в **README.html внутри архива**. [Исходный HTML инструкции](README.html).

## Что переведено и улучшено

- Диалоги, повествование, выборы, цели, предметы, обучение, мини-игры и интерфейс. Проверены **4440 текстовых записей**, включая архивные; намеренно пустые записи сохранены.
- Текст сверен с японской и английской версиями; другие встроенные языки использованы для уточнения смысла. Исправлены подтверждённые расхождения английского текста в числах и отдельных репликах.
- Выполнена литературная вычитка: единые имена и термины, естественные русские фразы, контекстные обращения персонажей, «ё» и русская пунктуация. Инструкции обращаются к игроку на «вы».
- Сохранён рисунок игровых шрифтов. Исправлены избыточные боковые поля кириллицы; длинные подписи управления сокращены.
- Перерисованы **17 изображений кнопок главного меню**, включая все состояния. Для рукописных подписей использован близкий по стилю Caveat.
- Установщик работает без интернета и загрузчиков модов, проверяет версию файлов, сохраняет оригиналы и умеет восстанавливать их.

## Удаление

В Windows выберите **«Восстановить оригинал»** в установщике. На Steam Deck откройте `Steam_Deck/3. Восстановить оригинал.desktop`.

Оригинальные файлы сохраняются в `Rain98_RU_Backup` внутри папки игры. Не удаляйте её до восстановления. Сохранения игрока установщик не меняет.

## Проверка и совместимость

Установка, контрольные суммы и восстановление оригиналов проверены готовым Windows-установщиком на отдельной копии реальных файлов игры. Полный визуальный проход обновлённой демоверсии пока не завершён. На физическом Steam Deck пакет пока не проверялся.

Другие сборки игры не поддерживаются автоматически. При обновлении Steam совместимость нужно проверить заново.

Rain98 и исходное оформление принадлежат авторам игры. Это фанатский перевод демоверсии, не официальный русский перевод полной игры. Пакет требует установленной игры и не содержит её исполняемый файл или сохранения.
